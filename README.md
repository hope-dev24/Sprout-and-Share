# Sprout & Share

Farm-to-table dining for two. A fictional restaurant website built as a portfolio project.

## Live site

([View the live site](https://eclectic-marzipan-0f5ba1.netlify.app/))

## Features

- Responsive, mobile-first one-page design
- Hamburger menu that closes on tap, with smooth scrolling
- Menu filtering by category
- "Open now" status
- Order cart with add, remove, and total, saved in the browser
- Reservation form with validation and a double-booking check
- Admin panel to update the daily special
- Newsletter signup message

## Built with

HTML, CSS, and JavaScript. No frameworks.

## Things to know

- This is a fictional restaurant. Nothing on the site is real.
- The cart, reservations, and daily special are saved with localStorage, so they live in each visitor's own browser. There is no server.
- The admin panel has no password.
- The newsletter form does not send emails.

## What I learned

Building this site taught me to take my time and debug every part of my code. Writing the code myself helped me understand what each part does, and I often found and fixed my own mistakes before asking anyone for help. I also learned to read the browser Console to track down errors. I like to learn and understand, not just copy, so I made sure I understood every line I wrote.
